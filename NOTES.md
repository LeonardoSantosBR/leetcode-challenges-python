* *two pointers* explicação: https://www.geeksforgeeks.org/dsa/two-pointers-technique/
- A Técnica de Dois Ponteiros é uma estratégia simples, porém poderosa, na qual você usa dois índices (ponteiros) que percorrem uma estrutura de dados - como um array, lista ou string - seja um em direção ao outro ou na mesma direção, para resolver problemas de forma mais eficiente.

Quando Usar *Two Pointers*:
Entrada Ordenada : Se o array ou a lista já estiver ordenada (ou puder ser ordenada), dois ponteiros conseguem encontrar pares ou intervalos de forma eficiente. Exemplo: Encontrar dois números em um array ordenado que somem um valor alvo.
Pares ou Subarrays : Quando o problema trata de dois elementos, subarrays ou intervalos, em vez de trabalhar com elementos individuais. Exemplo: Maior substring sem caracteres repetidos, máximo de uns consecutivos, verificar se uma string é palíndromo.
Problemas de Janela Deslizante : Quando você precisa manter uma janela de elementos que cresce/diminui conforme condições. Exemplo: Encontrar o menor subarray com soma ≥ K, mover todos os zeros para o fim mantendo a ordem.
Listas Ligadas (ponteiros lento–rápido) : Detectar ciclos, encontrar o nó do meio ou verificar a propriedade de palíndromo. Exemplo: Algoritmo de Detecção de Ciclo de Floyd (Tartaruga e Lebre).

* *binary search* explicação: https://www.geeksforgeeks.org/dsa/binary-search/
- é um algoritmo de busca que opera em um espaço de busca ordenado ou monotônico, dividindo-o repetidamente ao meio para encontrar um valor-alvo ou uma resposta ótima em tempo logarítmico O(log N).

- Condições para aplicar o algoritmo de busca binária em uma estrutura de dados:
1 - A estrutura de dados deve estar ordenada.
2 - O acesso a qualquer elemento da estrutura de dados deve ocorrer em tempo constante.

- Aplicações:
Busca em arrays ordenados.
Localização da primeira/última ocorrência ou da correspondência mais próxima em um array ordenado.


* *binary tree*: explicação: https://www.geeksforgeeks.org/dsa/binary-tree-data-structure/
- árvore binária é uma estrutura de dados hierárquica na qual cada nó tem no máximo dois filhos, denominados filho esquerdo e filho direito.
