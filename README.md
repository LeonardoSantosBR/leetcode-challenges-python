## Buscar um exercício

O script cria automaticamente uma pasta com o README e o esqueleto da solução em Python.

Por número:

```bash
python get_challenge.py 1
```

Por nome (use aspas se houver espaços):

```bash
python get_challenge.py "Two Sum"
python get_challenge.py "search in rotated sorted array"
```

O nome deve ser o título exato do exercício no LeetCode. Se não houver correspondência exata, o script exibirá possíveis resultados e não criará uma pasta, evitando importar um exercício diferente por engano.
